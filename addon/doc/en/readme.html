Modern Mono

Modern Mono is a pure-Python reconstruction of the 22 kHz and 11 kHz Monolog speech synthesizers.

This build also includes optional American-English entries converted from the community IBMTTS Dictionaries project and CMUdict. They are disabled by default, preserving the original Monolog dictionary and pronunciation rules.

CMUdict is maintained by Carnegie Mellon University and permits unrestricted redistribution with attribution. See the bundled CMUdict licence.

Voice settings

  • Voice: chooses the cleaner 22 kHz/16-bit voice or the original lower-fidelity 11 kHz/8-bit voice.
  • Rate boost mode: Off uses the original Monolog 0–9 range. Previous whole-unit retains the 0.6.8 mode, and Legacy overlap/add retains the faster boost from builds through 0.5.6.
  • Additional reading-speed experiments: Clean reading stops at the original S13 extension and progressively shortens pauses. The WSOLA variants also stop at S13, shorten punctuation pauses as the rate rises, then compress the complete rendered utterance using correlation-aligned windows: Crisp favours short consonant detail, Smooth favours continuity, Balanced sits between them, Maximum uses the strongest curve, and Balanced + shorter pauses applies the strongest pause reduction.
  • Excitation: controls sentence-level pitch movement. 50 preserves the native contours, 0 flattens them and 100 doubles their excursion.
  • Enable embedded setting commands: permits backtick pitch, speed, volume and delay commands.
  • Enable ASCII normalization: converts smart punctuation, Unicode dashes and accented Latin letters before pronunciation. It is enabled by default.
  • Use community American English dictionary: enables converted pronunciation corrections, abbreviation expansions and CMUdict fallback pronunciations. Leave this disabled for the most authentic original Monolog behaviour. Native Monolog entries retain priority.

Commands in NVDA text

Enable embedded setting commands before using these forms. The command remains active until another command changes the same setting.

  • `p8 sets pitch to 8; `p5 returns it to 5.
  • `s8 sets speed to 8; `s5 returns it to 5.
  • `v2 sets a quiet volume; `v5 returns it to the original level.
  • `d2 inserts a delay of two original timing units.

Example: “This is normal `p8 and this is higher `p5 and this is normal again.”

Engine user dictionary

Choose Modern Mono user dictionary from NVDA Preferences → Speech dictionaries. Enter a spelling or phrase and raw phonetics, then use Preview to hear the phonetics directly. Save or update applies the entry immediately; Delete removes it.

The entries are stored in modernmono-user-dictionary.tsv in NVDA’s user configuration directory beside nvda.ini.

Each non-comment line contains spelling, one tab character, and raw Monolog phonetics. Entries may contain spaces and matching is case-insensitive. Longer entries take priority.

# spelling<TAB>phonetics
hello	hEHl'OW
hello world	hEHl'OW|w'ERLXd

Phonetic controls

  • ' marks primary stress: hEHl'OW, “hello”.
  • " marks secondary stress.
  • / makes a pitch rise; \ makes a pitch fall.
  • [ makes a small pitch rise; ] makes a small pitch fall.
  • - makes a falling movement when it is not followed by a number.
  • | separates words.
  • ^ marks a phonetic boundary.
  • P0 through P9 set pitch inside raw phonetics.
  • S0 through S9 set speed.
  • V0 through V9 set volume.
  • D followed by a number inserts a delay.
  • A bare number supplies a duration or intonation target for the preceding phoneme chain.

Capitalization and syntax

Phoneme codes are case-sensitive. Enter multi-character codes exactly as shown. Raw phonetic strings use | between words.

Original data

The add-on contains the original 22 kHz and 11 kHz voices and default dictionary for local testing. Redistribution rights must be resolved before public publication.
